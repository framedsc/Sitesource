## Tips and Tricks

### Shadow enhancement and hotsampling

The shadow enhancement and hotsampling at high resolutions can both cause instability in this game. Save often. If the game looks frozen after a resolution change, give it a moment to rebuild its buffers.

### Hiding remaining UI

The tools include a ShaderToggler file for the UI elements the HUD toggle doesn't remove, such as low-health effects and warp icons.
