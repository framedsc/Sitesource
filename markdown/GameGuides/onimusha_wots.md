## Tools

* [REFramework](https://github.com/praydog/REFramework-nightly/releases)  
**Required**: the latest REFramework must be installed for ReShade and the camera tools to work (it bypasses the game's anti-tamper).
* [Camera tools by ghostinthecamera](https://patreon.com/ghostinthecamera)  
**Dynamic light spawning** (Advanced tools): point, spot, area and directional lights registered with the RE Engine, with full shadow control  
**Pose editor** (Advanced tools): per-bone posing with IK, hand and grip presets, gaze, facial morphs and animation playback, with poses saved and reloaded  
**[Features](https://ghostinthecamera.co.uk/tools/onimusha-way-of-the-sword/index.html)**: Typical camera tools features (camera, hotsampling, HUD etc), time control (engine pause also freezes cutscenes), ray tracing and path tracing control, post-process toggles, fixed exposure, near-camera fade removal, 4096 shadows, LOD removal

## Tips and Tricks

### Point light shadows

Point lights don't cast shadows by default. Enable *Expand shadow capacity* in the tools for point light shadows to work.

### Pose editor

The pose editor runs in the in-game overlay, so the overlay must be enabled.
