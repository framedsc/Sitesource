## Tools

* [Camera tools by ghostinthecamera](https://patreon.com/ghostinthecamera)  
**Dynamic light spawning** (Advanced tools): spot, point, omni and volume lights with shadows and projector settings, which can snap to the camera or player for quick placement  
**[Features](https://ghostinthecamera.co.uk/tools/blades-of-fire/index.html)**: Typical camera tools features (camera, hotsampling, HUD etc), time control with two pause methods, screen blur and depth of field removal, model LOD enhancement, 4x shadow resolution and shadow softness control, exposure adjustment, raindrop effect removal

## Tips and Tricks

### Lights

Delete any spawned lights once you're done with a shot. Loading into a new area with a spawned light will likely crash the game.

### Shadow enhancement

Don't toggle the shadow enhancement rapidly; it rebuilds render targets each time.
